# نوبت‌دهی آنلاین — کلینیک دندان‌پزشکی مهر

نمونهٔ متفاوت از بقیهٔ نمونه‌کارها: یک سیستم رزرو نوبت با تقویم، انتخاب پزشک و پنل مدیریت.

## اجرا

```powershell
cd C:\Users\Royan\portfolio
node start.js
```

`http://localhost:4200/booking/`

یا فایل `index.html` را مستقیم باز کن (کاملاً استاتیک).

## امکانات

- انتخاب خدمت (۶ خدمت با قیمت و مدت)
- انتخاب پزشک (۳ پزشک با تخصص)
- تقویم ۱۴ روزه با روزهای تعطیل غیرفعال
- نمایش ساعت‌های خالی و رزروشده
- فرم بیمار با اعتبارسنجی
- صدور کد پیگیری `MH-xxxxx`
- پیگیری نوبت با کد
- پنل مدیریت: فهرست نوبت‌ها و تغییر وضعیت
- ذخیره‌سازی در `localStorage`

## انتشار

مثل بقیه: ریپوی Public، آپلود محتوای این پوشه، Pages از `main` / root.

فونت داخل پوشهٔ `fonts` است، پس کاملاً خودکفاست.

## سفارشی‌سازی

- خدمات و قیمت‌ها: `app.js` → آرایهٔ `services`
- پزشکان: `app.js` → آرایهٔ `doctors`
- ساعات کاری و روزهای تعطیل: `app.js` → `slotsFor` و `isOpen`
- رنگ برند: `style.css` → `--teal`

## ریست دمو

در کنسول مرورگر:

```js
localStorage.removeItem('mehr_bookings');
localStorage.removeItem('mehr_seed');
location.reload();
```

## محدودیت‌ها

- دمو است؛ نوبت‌ها فقط در مرورگر همان بازدیدکننده ذخیره می‌شوند.
- ارسال پیامک یادآوری، پرداخت و ورود کاربر ندارد.
- برای نسخهٔ واقعی: سرور + پایگاه‌داده + پنل ادمین واقعی.

## ویدیوی نمونه (۳۰ ثانیه)

1. انتخاب خدمت → پزشک
2. انتخاب روز و ساعت (نشان بده یک ساعت رزروشده است)
3. پر کردن نام و تلفن
4. کد پیگیری
5. پنل مدیریت و تغییر وضعیت
